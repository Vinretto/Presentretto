# Presentretto
This is an app that you can easily use to create your presentations and export them to HTML so you can display them online.
___
What it still needs:

1. Can't yet select multiple objects.
2. It has no presenter view yet.
3. It has not transitions between slides.
4. It still needs a scrolling bar to navigate slides on the left pane.

___
You can access it from [here](https://presentretto.netlify.app/).
